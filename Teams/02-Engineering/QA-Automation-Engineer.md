# QA Automation Engineer

## Position Details
- **Department:** Engineering (QA & Reliability)
- **Reports To:** Head of QA & Reliability
- **Direct Reports:** None
- **Employment Type:** Full-time

## Role Summary
Builds and maintains automated test suites, CI/CD test pipelines, and quality infrastructure. Reduces manual testing burden by automating regression, performance, and integration tests.

## Core Skills
- Test automation framework development
- CI/CD test pipeline integration (@github-actions-templates)
- Performance and load testing (@k6-load-testing)
- Test data management
- Flaky test detection and maintenance (@systematic-debugging)

## Technical Skills
- Playwright, Cypress (E2E automation)
- Jest, Vitest (unit/integration automation)
- k6, Artillery (load testing) (@k6-load-testing)
- GitHub Actions (CI test pipelines) (@github-actions-templates)
- Docker (test environments)
- TypeScript, JavaScript
- API testing automation (Supertest)
- Lighthouse CI (performance regression) (@web-performance-optimization)
