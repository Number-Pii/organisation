# Senior Full-Stack Engineer

## Position Details
- **Department:** Engineering (Product Engineering)
- **Reports To:** VP of Product Engineering
- **Direct Reports:** None
- **Employment Type:** Full-time

## Role Summary
A versatile engineer who context-switches between frontend and backend without losing quality. Works on product features end-to-end, from database schema to UI component. Makes architectural decisions independently.

## Core Skills
- Full-stack feature development (UI to database)
- API design and frontend integration (@react-best-practices)
- Database design and query optimisation (@postgresql)
- Component development and state management (@react-best-practices)
- Independent architectural decision-making (@software-architecture, @architecture-decision-records)
- Cross-boundary debugging (@systematic-debugging)

## Technical Skills
- React, Next.js, TypeScript (frontend) (@react-best-practices)
- Node.js, Express, PostgreSQL (backend) (@postgresql)
- GraphQL and REST API development
- Prisma / Drizzle ORM
- CSS Modules, Framer Motion (@tailwind-patterns)
- Jest, Playwright (testing across stack)
- Docker, AWS, CI/CD
- Git, code review workflows (@code-review-excellence)

## Project Involvement
| Project Type | Role in Project | Authority Level |
|---|---|---|
