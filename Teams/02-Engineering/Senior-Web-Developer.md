# Senior Web Developer

## Position Details
- **Department:** Engineering (Client Engineering)
- **Reports To:** Lead Web Developer
- **Direct Reports:** None
- **Employment Type:** Full-time

## Role Summary
Delivers web application features for client projects to an exceptional standard. Works within project architectures set by the Lead Web Developer. Capable of owning feature domains end-to-end on client engagements.

## Core Skills
- Web application development (@react-best-practices)
- Responsive and accessible UI implementation (@accessibility-compliance-accessibility-audit, @tailwind-patterns)
- API integration and data handling
- Client project delivery to deadlines
- Code quality and testing (@code-review-excellence)

## Technical Skills
- React, Next.js, TypeScript, Vue.js (@react-best-practices)
- Node.js, Express, PostgreSQL (@postgresql)
- CSS/SCSS, CSS Modules, responsive design (@tailwind-patterns, @web-design-guidelines)
- REST APIs, GraphQL, CMS integrations
- Jest, Playwright, Cypress
- Git, CI/CD, Vercel/AWS deployment
